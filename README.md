# 🎬🎵 Movie & Music Recommender

A Python script that recommends movies and songs based on text similarity using TF-IDF and Cosine Similarity.

## 🎥 Demo Videos

- **Persian recommendation demo:** [Watch video](videos/demo-Persian.mp4)
- **English recommendation demo:** [Watch video](videos/demo-English.mp4)

## ✨ Features

- Movie recommendation based on title, description, and genre
- Song recommendation based on track name, artist, and playlist genre
- TF-IDF with bigrams for better accuracy
- Excludes the queried item from results

## 🛠 Requirements

- Python 3.8+
- Libraries: `pandas`, `numpy`, `scikit-learn`
